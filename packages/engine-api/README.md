# @brandonverzuu/engine-api

The RPC contract between the gateway Worker (`apps/expert-mcp`) and the private
rules Worker `expert-rules`. Types only: `CheckKind`, `Artifact`, `CheckRequest`,
`Finding`, `CheckResult` and `RulesService`, as fixed in
`docs/specs/expert-mcp/README.md`.

The private repo `brand0new/expertise` keeps a copy in `vendor/engine-api` until this
package is published. Change both together, and change the spec first.
